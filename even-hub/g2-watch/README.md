# Watch で G2

Apple Watch Series 8 で、Even G2 のこのページを操作します。VODCoach の機能は使いません。

Mac で、ダウンロードしたフォルダの中から次を実行します。

```bash
./watch-g2
```

白い QR の画像と案内のページが開きます。その画像を iPhone で読みます。案内のページは開いたままにします。

初回だけ、Xcode で `even-hub/g2-watch/watch/WristRemote.xcodeproj` を開き、自分の Apple Watch を選んで実行します。コードと API は入っています。

このページを開いているあいだ、タップ、ダブルタップ、デジタルクラウン、長押し、明るさが使えます。通知や Even のほかの画面は、メガネの横のタッチのままです。
